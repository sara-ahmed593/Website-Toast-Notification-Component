## Description

A simple and modern **Toast Notification system** built using **HTML, SCSS, and JavaScript**.  
It supports different notification types, smooth animations.       

## Features


-  Success, Error, Warning, and Info toasts
-  Custom styled UI with SCSS mixins
-  Auto-dismiss timer (4 seconds)
-  Manual close button
-  Smooth enter/exit animations
-  Responsive design support
